# LanLink(LAN 互連)

快速讓兩台 Windows 電腦直接連線傳檔的小工具,手機也能透過 Wi-Fi 熱點掃 QR Code 下載。單一執行檔,免安裝,介面支援繁體中文和英文。

目前版本:**0.0.2**,更新內容請看 [RELEASE_NOTES.md](RELEASE_NOTES.md)。

## 功能

- **一鍵設定:** 一台選 A、一台選 B,自動設定 IP、DNS 和防火牆,不影響 Wi-Fi 上網
- **拖放傳檔:** 把檔案或資料夾拖到對方圖示上就會傳送,可從這台瀏覽對方的資料夾並指定存放位置
- **多種連線:** 網路線、Thunderbolt/USB4、同一個 Wi-Fi、Wi-Fi 熱點
- **網頁下載:** 對方沒裝工具也沒設定時,用瀏覽器下載;使用 Wi-Fi 熱點時,手機掃 QR Code 也能下載
- **連線工具:** 連線測試、測速、顯示連線速度(含 2.5G、10G、20G)、遠端桌面
- **還原:** 改之前先備份網路設定,可手動還原,也可設定成退出時詢問或自動還原
- **介面:** 深色和淺色模式、Apple 和 Windows 兩種視窗按鈕樣式
- **背景執行:** 系統匣常駐收檔、開機自動啟動

## 系統需求

- Windows 10 或 11(64 位元)
- 內建的 .NET Framework 4.x,不需要另外安裝
- 改網路設定時需要按系統管理員確認(UAC)

## 使用方式

下載或自行編譯 `LanLink.exe` 後,放到固定磁碟上直接執行。

| 情境 | 兩台都要工具 | 改 IP | 預設網段 |
|---|---|---|---|
| 網路線對連 | 是 | 是 | `192.168.250.x` |
| Thunderbolt/USB4 對連 | 是 | 是 | `192.168.251.x` |
| 同一個 Wi-Fi | 是 | 否 | 沿用路由器配發的 IP |
| Wi-Fi 熱點 | 是 | 否 | `192.168.137.x` |
| 網頁下載(網路線或 Thunderbolt) | 只有分享端 | 分享端改為自動取得 | `169.254.x.x` |
| 網頁下載(Wi-Fi 熱點) | 只有分享端 | 否 | `192.168.137.x` |

### 網路線或 Thunderbolt

1. 接好線,兩台都開啟工具。
2. 確認網路卡選到正確的項目。Thunderbolt/USB4 會自動辨識,接上後優先選取。
3. 一台選「電腦 A」、另一台選「電腦 B」,各按一次「一鍵設定」。
4. 把檔案拖到右邊的電腦圖示上。

### 同一個 Wi-Fi

1. 兩台連到同一個 Wi-Fi,並在網路卡選單選 Wi-Fi。
2. 在「進階設定」的「對方 IP」填另一台畫面上顯示的 IP。
3. 各按一次「一鍵設定」。

公司 Wi-Fi 常禁止裝置之間互連,這時會連不到對方,請改用其他連線方式。

### Wi-Fi 熱點

1. 在一台打開「開啟 Wi-Fi 熱點」,畫面會顯示熱點名稱和密碼。按「密碼…」可以修改,這會一併改掉 Windows 行動熱點的密碼。
2. 另一台從 Windows 的 Wi-Fi 清單連上熱點,並在工具選 Wi-Fi。「對方 IP」會自動填入。
3. 開熱點的那台也會自動偵測到對方 IP。
4. 兩台各按一次「一鍵設定」。

熱點會分享這台的網路給對方。在公司電腦上使用前,請先確認公司規定允許。

### 網頁下載(對方沒有工具)

1. 接好網路線或 Thunderbolt 並選好網卡;或打開 Wi-Fi 熱點,在網卡選單選「Wi-Fi 熱點」。
2. 按「開網頁給對方下載」,把檔案或資料夾拖進清單。
3. 使用熱點時,另一台先連上熱點(畫面會顯示名稱和密碼)。手機可以按「手機 QR Code」,依序掃描連上熱點和開啟網頁。
4. 在另一台的瀏覽器輸入畫面上的網址,例如 `http://169.254.11.93:45451`;使用熱點時是 `http://192.168.137.1:45451`。

資料夾會打包成不壓縮的 zip。超過 4 GB 或檔案數達 65,535 個時無法打包,頁面會改列出每個檔案。頁面最下方也可以下載 `LanLink.exe`。

使用網路線或 Thunderbolt 時,分享端如果原本是固定 IP,會改為自動取得,原設定會先備份。按「還原設定」可以恢復。使用熱點時不會更改 IP。

## 收件位置

檔案存放位置的優先順序:

1. 傳送端指定的「送達位置」
2. 接收端設定的「收件位置」
3. 接收端 Windows 的「下載」資料夾

## 還原與退出

「還原設定」會還原所有有備份的網卡、移除工具建立的防火牆規則,並關閉熱點。

右上角齒輪的設定裡可以選擇退出時的行為。兩個選項只能開一個,都關閉時退出不做任何更動:

- **退出時詢問是否還原**(預設開啟)
- **每次退出自動還原**

關機或登出時不會還原,因為當下無法顯示 UAC 確認視窗。

## 安全說明

**請只在你信任的網路上使用。**

- 傳檔和網頁下載都**沒有加密**,網頁下載也**沒有密碼**
- 收檔只接受「對方 IP」傳來的連線,但來源 IP 可以被同一網路上的人假冒
- 在共用的 Wi-Fi 上,同網路的人有機會攔截內容或假冒對方,敏感檔案請改用網路線或 Thunderbolt
- 網頁下載只接受 `169.254.x.x` 和熱點 `192.168.137.x` 的來源,而且只提供清單裡的檔案和 `LanLink.exe`;知道熱點密碼的裝置都能下載
- 離開 Wi-Fi 網路前建議按「還原設定」,防火牆規則不會自動移除

## 技術細節

| 項目 | 內容 |
|---|---|
| 傳檔 | TCP 45450 |
| 網頁下載 | TCP 45451 |
| 防火牆規則 | `LanLink`、`LanLink-RDP`、`LanLink-Web`、`LanLink-WebHotspot` |
| 設定和備份 | `%LocalAppData%\LanLink` |
| 開機啟動 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`,值名稱 `LanLink` |
| 熱點 | 透過系統內建的 PowerShell 呼叫 Windows 行動熱點 API |

## 從原始碼編譯

不需要 Visual Studio 或 SDK,使用 Windows 內建的 C# 編譯器:

```bat
build.bat
```

腳本會產生 `LanLink.exe`,接著自動執行自我檢查,失敗時會回傳錯誤。也可以手動執行 `LanLink.exe --selftest`,結束代碼 0 代表通過。

| 檔案 | 用途 |
|---|---|
| `Program.cs` | 全部程式邏輯(限 C# 5 語法) |
| `Main.xaml` | 介面 |
| `app.ico`、`LAN_Tool_Apple_Flat.svg` | 程式圖示和原始檔 |
| `make-icon.ps1` | 由 SVG 產生 `app.ico`,只有圖示改動時才需要執行 |

未經程式碼簽署的執行檔,可能被 SmartScreen 或防毒軟體警告或封鎖。
